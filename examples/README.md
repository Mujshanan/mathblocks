# Examples

- [first_components.py](first_components.py) — MathLive input, KaTeX static rendering, Text annotations, and Result output.
- [structured_visual.py](structured_visual.py) — Matrix, Vector, Graph, and Diagram.
- [jupyter_app.py](jupyter_app.py) — display all components in Jupyter Notebook or JupyterLab.
- [marimo_app.py](marimo_app.py) — compose components in a reactive Marimo app.

Jupyter examples require MathBlocks and IPython in the active kernel environment.
The Marimo example requires the optional dependency: pip install "mathblocks[marimo]".
